# Claude Code prompt — D1: pin the environment, reproduce the published results, and establish the baseline (autonomous)

Run from the project root (`.../work/OxygenModel`). This is the FIRST prompt in the OxygenModel
D-series and it is deliberately a REPRODUCTION task, not a science task: pin everything, make the
pipeline run unattended, regenerate every published figure and table from the deposited raw data,
check the restructured modular pipeline against the original scripts that actually produced the
paper, and write a baseline report. It changes NO analysis decision.

NOTE TO USER: launch in an auto-approving mode. This pipeline is small — 15 taxa x 5 replicates =
75 series, no MCMC, no genome-scale model — so expect minutes, not hours.

CONTEXT. `icakin/OxygenModel` is the reference implementation of the oxygen-dynamics method
published as Cakin et al. 2026, *ISME Communications* 6:ycag024. The raw data has just been
deposited. The repository was recently restructured (commit `ed5e1a6`) from four monolithic scripts
into a modular pipeline (`config.R`, `01`–`10`, `run_all.R`), and the pre-restructure code is
retained under `scripts/original_scripts/` (`OxygenModel.R`, `CUE.R`, `MC.R`, `05CUTOFF.R`,
`Simulation.R`). **The restructure has never been checked against the published outputs.** That
check is the point of D1: `results/figures/` and `results/tables/` hold committed outputs from the
ORIGINAL scripts, so we can ask directly whether the modular pipeline reproduces them.

Two smaller signals that it may not, both worth resolving: `run_all.R`'s header states the OD600 /
flow-cytometry growth-rate comparison is "intentionally not included", but `06_main_figures.R` does
in fact emit `Fig_3_growth_rate_comparison.tiff`, `Fig_4_growth_rate_regression_normalized_combined
.tiff` and `Fig_5_BlandAltman_AllReplicates_LME.tiff`; and `10_temperature_cue.R` — which produces
the *Pseudomonas* CUE result, Figure 7 — is not in the runner loop at all.

The project has also decided to go MULTI-DATASET: the engine should eventually ingest both the
bacterial series here and the *Candida* temperature series (four *C. auris* clades +
*C. parapsilosis*, 12 temperatures). D1 does not implement that, but it must INVENTORY what stands
in the way, so the generalisation can be scoped.
